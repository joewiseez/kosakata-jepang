語帳 — Kosakata Jepang
Aplikasi web sederhana untuk mencatat dan menghafal kosakata bahasa Jepang, mulai dari kata sehari-hari sampai level N4. Semua data tersimpan otomatis di browser (localStorage) — tidak perlu login atau internet setelah halaman dimuat.
🔗 Live site: https://joewiseez.github.io/kosakata-jepang/
Fitur
Tab Catatan — tambah kosakata baru dengan Kanji, Hiragana, Romaji, Arti, dan contoh kalimat. Bisa dicari dan dihapus.
Starter pack — tombol untuk langsung mengisi ±150 kosakata dasar sehari-hari sampai N4 (kata benda, kata kerja, kata sifat, dll).
Tab Latihan — mode flashcard dengan 3 arah hafalan:
Kanji → arti
Arti → kanji
Hiragana → romaji
Bisa diacak, dan setiap kartu bisa ditandai "Sudah hafal" atau "Belum hafal".
Statistik — jumlah total kata, yang sudah hafal, dan yang perlu diulang.
Bisa di-install sebagai aplikasi di HP lewat "Add to Home screen".
Cara pakai
Buka link live site di atas.
Klik "Muat starter pack" di tab Catatan untuk mulai dengan kosakata dasar, atau tambahkan kosakata sendiri satu per satu.
Pindah ke tab Latihan untuk menghafal pakai flashcard.
Data otomatis tersimpan di browser kamu — tidak akan hilang selama tidak menghapus data browser.
Dibuat dengan
HTML, CSS, dan JavaScript murni (tanpa framework), disimpan sebagai satu file index.html.
